Migration des recettes

Cette page copie toutes les recettes et leurs photos de l'ancienne base (recettes-1b272) vers la base du dashboard (dash-board-maison).

  1. Publie d'abord les nouvelles règles Firestore dans la base du dashboard.
  2. Clique sur « Copier les recettes » et attends la fin.
  3. Vérifie le carnet, puis supprime ce fichier migration.html du site.

L'ancienne base n'est pas modifiée. Tu peux relancer la copie sans risque : les recettes déjà copiées sont ignorées.
